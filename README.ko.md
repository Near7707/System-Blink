# System Blink

*[English](README.md)*

실리태번 롤플에 붙이는 한국 시스템물 느낌의 **시스템** 확장이에요.
이야기 도중에 반투명 시스템창이 "띠링!" 하고 떠요 — *「[일일 퀘스트가 도착했습니다]」*.
이야기 속에서 퀘스트를 깨고 포인트를 모아서 **개인 상점**에서 써요.

이번 버전(0.5.4): 시스템창, 튜토리얼, 일일 퀘스트, 상점, 가방, 일상 모드, 돌발 퀘스트, 히든 퀘스트, 메인 목표,
조건이 여러 개인 퀘스트, **난이도와 페널티**, **스킬과 뽑기** + **시스템 말투 세 가지**와 반응·후원하는 **구경꾼**.

## 설치

실리태번 → 확장 → *Install extension* → 아래 주소 붙여넣기:

```
https://github.com/Near7707/System-Blink
```

처음에는 영어로 나와요. ⚙ 설정의 **Language**에서 **한국어**를 고르세요.

## 쓰는 법

- **채팅방에서 시스템 깨우기**: 떠 있는 육각 버튼(또는 ✨ 마법봉 메뉴의 *System Blink*)을 누르고 *[시스템 깨우기]*.
  채팅방마다 포인트·가방·퀘스트·튜토리얼이 따로예요. 다른 채팅방은 건드리지 않아요.
- **튜토리얼**(채팅방마다 한 번): 시스템창 열기 → 첫 일일 퀘스트 깨기 → 상점에서 하나 사기 → 가방에서 써 보기.
  보상 100P + 뽑기권 1장. 건너뛸 수 있어요.
- **일일 퀘스트**(하루 2~3개)는 판정하기 쉬운 짧은 행동이에요 — *「누군가에게 음료 사 주기」*.
  AI 답장이 끝날 때마다 작은 요청 하나가 이야기를 읽고 판정해요. 근거(이야기 속 한 줄)는 퀘스트 탭에 보여요.
  잘못 판정했으면 퀘스트를 눌러 *직접 완료* / *완료 취소*. 그 답변을 다시 뽑거나 지우면 완료와 포인트도 같이 취소돼요.
- **돌발 퀘스트**: 답장마다 주사위를 굴려서 가끔 떠요 — *「[돌발 퀘스트가 발생했습니다]」*. 제한은 답장 몇 번(기본 3번, 난이도에 따라 달라짐).
  *[수락]* / *[거절]*. 이야기 확인과 같은 요청에서 만들어져서 AI 호출이 늘지 않아요. 답변을 다시 뽑으면 그 답장은 다시 세요.
- **히든 퀘스트**: 가끔 이야기 확인 때 우연히 한 행동을 찾아서 보라색 히든 퀘스트를 열어요. 시간 제한·페널티 없음.
- **메인 목표**: 채팅방마다 큰 목표 하나, 3~5단계. 버튼을 누르면(설정이 "자동"이면 바로) AI가 캐릭터 카드를 보고 제안하고(모든 줄을 고칠 수 있어요),
  다음 단계는 앞 단계를 깰 때 그때 이야기에 맞춰 만들어요. 단계에 조건이 두 개면 조건마다 따로 체크하고, 둘 다 하면 포인트를 받아요.
- **난이도**(채팅방마다 따로, 기본 *Off* = 지금과 같음): *Easy* / *Normal* / *Hard* / *Hell*.
  퀘스트 어려움·보상(×0.8 / ×1 / ×1.5 / ×2)·페널티만 바꿔요. 분위기는 이야기를 따라가고, AI 판정 기준도 그대로예요.
  Hard 퀘스트는 조건 2개, Hell은 2~3개, 돌발 퀘스트는 시간이 짧아져요.
  - *Normal*부터: 다음 날까지 못 깬 일일 퀘스트, 거절하거나 시간이 지난 돌발 퀘스트는 보상의 절반이 차감돼요.
  - *Hard*: 디버프 *[바가지] 상점 가격 +20%*(다음 날까지)가 더해지고, 깨면 풀리는 페널티 퀘스트(보상 없음)가 와요.
  - *Hell*: 가방에서 물건 하나를 무작위로 잃어요. 시스템창이 붉어져요.
  - 포인트는 0 밑으로 내려가지 않아요. 답변을 다시 뽑아 돌발 퀘스트가 되살아나면 차감도 돌아와요.
    바꾼 난이도는 새로 오는 퀘스트부터 적용돼요. 튜토리얼 중엔 적용 안 돼요.
- **상점**: *일일* 상점(매일 4~6개 무작위, 특이한 물건)과 *상시* 상점(늘 있는 물건 + *[새로 진열]*로 AI가 만드는 물건).
  등급별 가격: 일반 / 희귀 / 영웅 / 전설.
- **가방**: *[사용]*하면 다음 메시지의 답장(다시 뽑기 포함)에서 AI가 알게 돼요.
- **스킬**: 등급 F → S, 그 위에 **SS**(아주 드물게). *패시브*는 늘 켜져 있어서 AI가 매 답장마다 알고 어울릴 때 드러내요.
  *액티브*는 *[사용]*으로 써요(쿨타임·마나 없음). 내 다음 메시지와 함께 AI에게 알려요. 능력치·숫자는 없어요.
  상태 탭에 벌집 모양으로 놓이고, 누르면 설명이, *[자세히]*로 자세한 화면이 열려요.
  - 얻는 곳: **뽑기권**(*가방 → [열기]*: 스킬이나 물건, 엉뚱한 게 자주 나와요. S·SS는 화면이 번쩍), 가끔 일일 상점에 나오는 **스킬북**(사면 바로 배움),
    메인 목표 달성(꼭), 히든 퀘스트(가끔).
  - **숨은 효과**: 낮은 등급(F·E) 스킬에는 숨은 쓸모가 있어요. 이야기 확인이 그 스킬이 이야기 속에서 빛난 순간을 찾으면 열려요.
    등급은 그대로, 효과만 더해져요. 그 답변을 다시 뽑으면 다시 닫혀요.
  - 등급은 확장이 주사위로 정하고, AI는 그 등급에 맞는 스킬만 써요. 스킬은 난이도와 상관없어요.
- **말투**(채팅방마다 따로): 시스템의 색과 문구가 바뀌어요. 포인트 규칙은 같아요.
  - **게임형** — 푸른 홀로그램, 딱딱한 게임 알림(지금까지와 같음).
  - **후원형** — 금빛. 일일 퀘스트가 *「[성좌들이 오늘의 볼거리를 기다립니다]」*로 오고, 보상은 *「후원 10P」*, 상점은 **도깨비 보따리**.
    구경꾼은 *「밤하늘을 세는 자」* 같은 별명을 가진 **성좌**가 돼요.
  - **협박형** — 붉은색, 화면이 살짝 떨려요. 일일 퀘스트는 *생존 과제*, 상점은 **수상한 암시장**.
    *Normal* 난이도부터 실패하면 포인트 대신 **경고**가 쌓여요(Hard·Hell의 디버프·물건 잃기는 그대로).
    **경고 3개면 큰 사건**: 이야기 속에 위험한 일이 벌어진다고 AI에게 한 번 알리고, 경고는 0부터 다시 쌓여요.
    암시장에서 *경고 지우개*(경고 −1)를 팔아요. 큰 사건은 되돌릴 수 없어요.
- **구경꾼**(켜고 끄기): 가끔 오른쪽 위에 작은 알림이 떠요 — *「[누군가가 당신의 선택을 흥미로워합니다]」*.
  *가벼운 방식*은 미리 만든 문장(AI 호출 없음), *풍부한 방식*은 AI가 장면을 보고 한 줄을 써요(구경꾼이 반응할 때 한 번 더 불러요).
  가끔 5~30P를 **후원**하고(금빛 알림, 그 답변을 다시 뽑으면 같이 취소), 아주 드물게 스킬(F~C)도 선물해요. 이야기 속에는 나오지 않아요.
- **일상**: 날짜·시간대·날씨·장소·오늘 일정. AI 확인이 바뀐 걸 알아채고, 직접 고칠 수도 있어요.
  이야기 속 날이 바뀌면 입력칸 위 띠가 *「다음 날로 넘길까요?」* 하고 물어요. 며칠이 지나도 정산은 한 번만.
- **기록 카드**: 퀘스트 완료(시간이 지난 돌발 퀘스트 포함)·일상 변화·숨은 효과 개방·후원·물건과 스킬 사용이 메시지 아래 작은 카드로 남아요. 화면에만 보여요.
  기록은 전부 보관해서 오래된 메시지에도 카드가 남아요.
- **시스템 기록 넣어 채팅 내보내기**: *데이터 → 시스템 기록 넣어 채팅 내보내기*로 채팅 전체를 순서대로, 메시지마다 시스템이 한 일을
  붙여서 내려받아요(.txt / .json). 새 파일만 만들고 채팅은 안 바꿔요.

## 안전하게

- 캐릭터 카드·채팅 파일·채팅 메타데이터·메시지 글은 고치지 않아요. 모두 확장 설정에 저장해요
  (떠 있는 버튼 위치만 이 기기 브라우저에).
- AI에게 주는 짧은 줄(퀘스트·가방·스킬·일상·물건과 스킬 사용)은 **본 답변에만** 들어가요. 다른 확장의 요청에는 안 들어가요.
  이 줄은 AI에게 시스템 알림을 직접 쓰지 말고, 다른 상태 블럭은 그대로 쓰고, 퀘스트를 대신 하지 말라고 알려요.
- 슬래시 명령어 없음. 꺼 두면 팝업·AI 호출·카드 모두 없어요.
- 채팅을 분기하면 시스템도 복사되고, 이름을 바꾸면 따라가요.
- 0.1에서 업데이트하면 저장 데이터가 새 형식으로 저절로 옮겨져요. 옮기기 전 데이터는 이 기기 브라우저에 먼저 남겨 둬요
  (*데이터 → 0.2 이전 데이터*로 내려받기).

## 설정

⚙ 설정과 실리태번 확장 설정 양쪽에 모든 설정이 있어요(같은 값).
말투와 난이도(채팅방마다), 구경꾼(켜기·방식·후원), 포인트 배율, 하루 기준(이야기 속 날짜/실제 시간), 이야기 확인 빈도(매 답장/3번에 한 번/수동), 시스템이 보이는 범위,
일상 칸을 AI에게 알려 주기, 퀘스트 기회 만들어 주기, 돌발 퀘스트 빈도·뜬 뒤 쉬는 시간, 히든 퀘스트 켜기, AI 목표 제안(자동/수동/끔), 채팅방마다 **세계관 지시**(퀘스트·물건 만들 때 씀),
상점 직접 등록, 확인·생성용 연결 프로필(싸고 빠른 모델이면 충분), 백업·복원, 보낸 내용 보기.
